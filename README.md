Two lines to the writer's past self: the first warns about one specific moment — when your brother calls from the payphone at the bus station at 11 p.m. on a Tuesday, pick up, because it is the last time he will ask for help — and the second explains, in a single sentence, why that moment mattered more than it seemed at the time.

## Run it

```bash
python3 main.py
```

This writes exactly two lines to `/output/entry.txt`. Override the destination with the `OUTPUT_PATH` environment variable. The output is byte-identical on every run — deterministic, offline, and stdlib-only.
